# Data Handling Project (CSV + JSON)

## Features
- Read CSV file (List)
- Read CSV file (Dict)
- Write CSV file
- Read JSON file
- Write JSON file
- Write CSV file (Dict)

## Tech Used
- Python
- CSV module
- JSON module

## How to Run
- python csv_read.py
- python csv_read_dict.py
- python json_read.py
- python csv_write.py
- python json_write.py
- python csv_write_dict.py

## All Operation Run
- python main.py

## File Modes

r — For Read (file ko sirf padhne ke liye)
w — For Write (file me likhne ke liye, purana data delete ho jata hai)
a — For Append (file ke end me naya data add karne ke liye)
r+ — For Read and Write (padhna aur likhna dono)
w+ — For Write and Read (likhna aur padhna dono, purana data delete ho jata hai)
a+ — For Append and Read (data add karna aur padhna dono)
x — For Create (sirf nayi file banane ke liye, agar file pehle se ho to error)
